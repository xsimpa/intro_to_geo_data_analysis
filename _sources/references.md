# External resources

**Python Fundamentals:**
- [Programming for Everybody (Getting Started with Python)](https://www.py4e.com). We will follow this textbook for roughly the first half of the lecture.

**Intorduction to programming in atmospheric sciences**
- Fabien Maussion's original course offered UIBK [Introduction to Programming](https://fabienmaussion.info/intro_to_programming/welcome.html), which heavily inspired this course and jupyter notebook creation.

**Primer on Programming in Python**
- Imperial College London’s excellent notebook on [Primer on Programming in Python and Mathematical/Computational Techniques for Scientists and Engineers](https://primer-computational-mathematics.github.io/book/intro.html)

**Earth and Environmental Data Science**
- Another great reference to learn how to code in python in the geosciences is Columbia University's [Earth and Environmental Data Science](https://earth-env-data-science.github.io/intro.html)
